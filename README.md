
# 🌌 NIGHTSHIFT OS 5.0

A futuristic desktop experience built with Electron.

## ✨ Features

- 🌐 Animated sci-fi desktop interface
- 🖥️ Multi-window desktop environment
- 💻 Built-in terminal with useful commands
- 📝 Notes with local autosave
- 📁 File explorer with local text-file preview
- 🎨 Customizable cyan, blue and other neon themes
- 📊 Demo system-monitor dashboard
- 🔔 Toast notifications
- 🪟 Windows desktop application

## 🛠️ Built With

- HTML
- CSS
- JavaScript
- Electron

## 🚀 Run Locally

Install [Node.js](https://nodejs.org/), then run:

```bash
npm install
npm start
```

## 📦 Windows Installer

Open the **Releases** section to download the
Windows installer, when a release is available.

## ⚠️ Notes

System-monitor readings are simulated demo data.
The application is a desktop interface, not a real
operating system.
